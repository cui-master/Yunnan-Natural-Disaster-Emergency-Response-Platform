# Design Context — 云南省自然灾害应急响应平台（前端）

> 本文件由 impeccable 技能读取，用于约束所有前端设计决策，避免泛 AI 审美。

## Target Audience（受众）
- **主要用户**：省/市/县三级应急指挥中心值班人员、指挥长、资源调度员、灾情信息员。
- **使用情境**：7×24 值班大屏与办公电脑，高压力、强时效的灾情研判与资源调度场景；信息密度高，容错率低。
- **次要用户**：演练评审专家、上级检查人员（短时间浏览大屏）。

## Use Cases（核心任务）
1. 实时灾情一张图监测与等级研判
2. 救灾资源调度与可调资源预警
3. AI 处置方案生成与签发
4. 多角色协同（信息员上报 → 指挥研判 → 资源调度）
5. 消息/告警的即时触达（消息盒子）

## Brand Personality / Tone（品牌调性）
- **关键词**：权威、冷静、可信、克制、有焦点的"指挥中心风"。
- **不做**：炫技、娱乐化、青紫渐变/毛玻璃滥用等泛 AI 审美。
- **美学方向**：意图明确的"自信的极简 + 一个强烈焦点"。焦点 = 大屏上的关键灾情指标（大号等宽数字 + 应急红强调）。
- **差异化记忆点**：应急红 `#e03e2f` 作为稀缺强调色（遵循 60-30-10：中性底 60% / 文字边框 30% / 强调 10%），配合等宽展示字体呈现数据，形成"指挥大屏"的专业质感。

## Constraints（约束）
- 技术栈：Vue 3 + Vite + Element Plus + ECharts + Leaflet（不可替换组件库）。
- 可访问性：正文 ≥16px、对比度满足 WCAG AA、尊重 `prefers-reduced-motion`。
- 字体：中文用系统字体栈（PingFang SC / Microsoft YaHei）；拉丁数字与标题可用 Sora 等展示字体做渐进增强（离线降级到系统字体）。
- 配色：中性色向品牌色微暖调（极低 chroma），避免纯黑纯白；用 OKLCH 表达。
- 动效：仅用 ease-out-quart / ease-out-expo，绝不用回弹/弹性缓动；位移只用 transform/opacity。

## Differentiation（让人记住的一点）
在冷静的中性底上，用"大号等宽红色数字 + 脉冲标点 + 实时事件流"制造紧张的指挥感——让用户一眼知道"此刻最该关注什么"。
