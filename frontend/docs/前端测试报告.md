## 三、关键实现点（供联调确认）

1. **AI 流式（SSE）**：`src/api/plan.ts` 的 `generatePlanStream` 在真实模式使用 `fetch + ReadableStream` 解析 `data: {json}\n\n` 帧，兼容 POST 方式；Mock 模式用 `simulatePlanStream` 逐 token 回放。
2. **WebSocket 实时事件**：`src/utils/websocket.ts` 携带 token 连接 `VITE_WS_BASE`，大屏 `EventTicker` 展示。
3. **图片上传**：`el-upload` 自定义 `http-request` → `POST /api/upload`，后端转发 MinIO，返回 URL 列表。
4. **接口契约**：前端类型集中在 `src/types/index.ts`，与后端 Swagger / AI OpenAPI 对齐（统一 `ApiResp<T>` 包装、工单状态机枚举、角色枚举）。

## 五、缺陷与风险
- 无阻塞缺陷。
- 风险：真实环境下 OpenStreetMap 瓦片需公网；内网部署建议替换为高德/天地图瓦片（已预留 `DisasterMap.vue` 中 tileLayer 切换点）。
