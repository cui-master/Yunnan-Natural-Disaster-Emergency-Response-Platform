# 云南省自然灾害应急响应平台 — 前端测试用例

> 角色：前端开发负责人（角色 1）
> 技术栈：Vue 3 + TypeScript + Vite + Pinia + Element Plus + ECharts + Leaflet
> 联调模式：`VITE_USE_MOCK=true` 走前端 Mock 联调层；`false` 走真实后端（Spring Boot）/ AI 服务（FastAPI）

## 一、测试环境

| 项 | 说明 |
| --- | --- |
| 操作系统 | Windows 11 / macOS |
| 浏览器 | Chrome ≥ 110、Edge ≥ 110 |
| Node 版本 | 22.x（开发态） |
| 运行方式 | `npm install` → `npm run dev`（默认 5173 端口） |
| 联调数据源 | Mock 联调层（`src/api/mock`）/ 真实后端代理 |

## 二、接口联调用例（对接角色 2 / 角色 3）

| 编号 | 接口 | 方法 | 前端调用点 | 预期 |
| --- | --- | --- | --- | --- |
| API-01 | `/api/auth/login` | POST | 登录页 | 返回 token + userInfo，写入 localStorage |
| API-02 | `/api/disasters` | GET | 审核台/大屏 | 分页返回工单列表，filters 生效 |
| API-03 | `/api/disasters` | POST | 灾情上报 | 创建工单，状态=待核验 |
| API-04 | `/api/disasters/review` | POST | 审核台 | 状态机正确流转 |
| API-05 | `/api/disasters/stats` 等 | GET | 大屏 | 统计/分布/趋势数据正确 |
| API-06 | `/api/resources` | GET | 资源查询 | 资源列表 + 过滤 |
| API-07 | `/api/resources/dispatch` | POST | 资源查询 | 生成调度记录，冲突检测返回 conflict |
| API-08 | `/api/dispatches/:id/cancel` | POST | 调度看板 | 资源释放，状态=已取消 |
| API-09 | `/ai/plan/generate`（SSE） | POST | 方案工作台 | 流式返回方案 chunk |
| API-10 | `/api/plans/:id` | PUT | 方案工作台 | 保存人工修改 |
| API-11 | `/api/knowledge` | GET/POST/DELETE | 知识库 | 文档入库/删除 |
| API-12 | `/api/audit/logs` | GET | 审计日志 | 日志分页 |
| API-13 | `/api/system/*` | GET/POST/PUT | 系统管理 | 用户/角色/配置 |
| API-14 | `/api/upload` | POST | 上报/知识库 | 返回图片 URL（MinIO） |
| API-15 | `/ws`（WebSocket） | WS | 大屏实时流 | 事件状态变更推送（真实模式） |

## 三、功能测试用例

### 3.1 登录与鉴权
- TC-01 正确账号登录（demo：commander/123456）→ 跳转大屏，侧边栏按角色渲染
- TC-02 错误密码 → 提示"用户名或密码错误"
- TC-03 未登录访问 `/dashboard` → 重定向 `/login`
- TC-04 已登录访问 `/login` → 重定向 `/dashboard`
- TC-05 退出登录 → 清除 token，回登录页

### 3.2 灾情态势大屏（Dashboard）
- TC-10 地图渲染云南灾情点，颜色按等级区分
- TC-11 统计卡片数值与接口一致
- TC-12 类型分布饼图 / 州市柱状图 / 趋势折线图渲染正常
- TC-13 Mock 模式实时事件流每 ~4.5s 新增一条；真实模式 WebSocket 推送
- TC-14 窗口缩放时图表自适应 resize

### 3.3 灾情上报
- TC-20 表单必填校验（标题/类型/等级/州市/区县/位置/描述）
- TC-21 选择州市自动带出中心坐标
- TC-22 图片上传（el-upload 自定义 http-request → `/api/upload`）成功回显
- TC-23 提交后工单进入"待核验"，列表更新

### 3.4 信息审核工作台
- TC-30 待核验工单"确认/驳回"流转
- TC-31 已确认工单"开始处置"→处置中
- TC-32 处置中工单"结束工单"→已结束
- TC-33 详情抽屉展示灾情信息、图片预览
- TC-34 状态筛选生效

### 3.5 应急方案工作台（AI 亮点）
- TC-40 选择工单点击"生成方案"→ SSE 流式逐段输出
- TC-41 流式过程中"停止"可中断
- TC-42 生成完成后展示引用来源（RAG）与合规审查评分
- TC-43 人工修改段落内容，"保存修改"写入
- TC-44 "审批通过"将方案置为 APPROVED

### 3.6 救援资源 / 调度
- TC-50 资源列表过滤（类型/状态/关键词）
- TC-51 多选资源 → 选择目标工单 → 确认调度
- TC-52 被占用/锁定资源触发 conflict=true 并在结果中提示
- TC-53 调度看板展示记录，KPI 统计正确
- TC-54 取消调度 → 资源状态释放

### 3.7 知识库 / 审计 / 系统
- TC-60 知识库分类过滤、入库（分块向量化提示）、删除
- TC-61 审计日志分页与关键词查询
- TC-62 系统管理：用户/角色权限(RBAC)/配置三页签切换正常
